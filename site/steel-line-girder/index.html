Steel Line Girder Check

Design check of continuous composite steel plate girders, rolled beams and straight tub girders, with performance ratios for every limit state and a load rating: AASHTO LRFD (9th or 10th edition, HL-93) with MBE LRFR, or the AASHTO Standard Specifications 17th edition Load Factor Design (HS loading) with MBE LFR. Tub girders are checked to the LRFD 10th edition (Article 6.11). Edit any input and results update. A line girder rating output file can be imported with Import other file to fill the inputs.
